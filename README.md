# Snake Game

A classic Snake game implemented in both Python (Pygame) and Web (HTML/CSS/JavaScript) versions.

## Python Version

Build a snake game using Python and Pygame.

### Requirements

- Python 3.x
- Pygame

### How to Run

1. Install Pygame: `pip install pygame`
2. Run the game: `python "snake game.py"`

## Web Version

The web version is built using HTML5 Canvas, CSS, and JavaScript for deployment on Vercel.

### How to Run Locally

1. Open `index.html` in your web browser.

### Deployment to Vercel

1. Push this repository to GitHub.
2. Go to [Vercel](https://vercel.com) and sign in.
3. Click "New Project" and import your GitHub repository.
4. Vercel will automatically detect it as a static site and deploy it.
5. Your Snake game will be live at the provided Vercel URL.

### Features

- Classic Snake gameplay
- Score tracking
- High score persistence (localStorage for web, file for Python)
- Responsive controls
- Game over and restart functionality
